# SO101 接口与演示数据验收

本页区分公共接口可运行与演示可用于训练。两者独立验收；环境短测通过不代表抓取成功，也不使候选数据自动成为专家演示。

下方实测记录对应所列2026-10-22固定代码与数据，不是后续所有接口的统一验收。新增[视觉规则基准](SCRIPTED_LIFTCUBE.md)和[自研末端开发层](PLANAR_EE_DEVELOPMENT.md)分别记录结果与限制；它们不会解除本页的演示准入缺口。

## 验收对象

- 代码起点：`0d61747`，课程 LiftCube 适配器；不是 PickOrange 或正式多物体任务。
- 环境：Isaac Sim 4.5.0 / Isaac Lab 2.1.1 / LeIsaac 0.1.2 配套镜像。
- 策略输入：单 front RGB、六关节反馈与上一发送目标。兼容速度/末端补零不作真实测量使用。
- 控制：六维绝对电机目标，经公共转换发送为驱动关节目标；请求、发送与反馈分别记录。

实际部署绑定、原始运行日志和资源记录不放入公共仓库。

## 接口检查

软件回归入口见 [LiftCube AGENTS](../course/liftcube/AGENTS.md#7-改动后的最小验证)。实际环境验收需要另外核对：

1. 原生关节名称及顺序与 `JOINT_NAMES` 一致；实测关节状态不缺失、不补造。
2. 小幅诊断命令的电机值与弧度转换一致，驱动目标与发送值一致；反馈不要求瞬间到达目标。
3. 上一命令槽记录发送目标，速度/末端兼容槽保持补零；不将物体真值输入策略。
4. front 图像尺寸、数值范围与渲染就绪状态；物理步和纯渲染更新分开。
5. 原生环境周期及策略动作保持次数；终止时不继续执行缓存动作。
6. 截断时返回 reset 前末态，不能用下一回合初帧代替。

## 下一步通过条件

### 原生请求与执行限幅的配对诊断

95°来自当前SO101 USD资产的腕俯仰上限，不是给演示标签另定的统计阈值。请求目标可以超过实际可达范围：原生位置控制器接收目标，关节运动仍受物理约束；请求超过上限本身不证明轨迹抓取失败，也不证明它兼容公共动作接口。

已有单回合严格检查仅执行第0帧的两个tick，第1帧腕目标96.5104°在发送前被诊断检查拒绝。因此它不是完整重放，更不是抓取失败成绩。当前尚无完整原生请求/执行限幅配对结果。

后续比较应固定同一回合、正常reset的初态、seed、动作语义、保持周期、相机、物理和成功条件，只改变执行时是否限幅：

| 组别 | 输入标签 | 发送到原生控制器的目标 |
| --- | --- | --- |
| 原生请求 | 保留原值 | 只按明确假设转换单位，不限幅 |
| 执行限幅 | 同一份原值 | 转换后按原USD范围限幅，另存限幅差值 |

原生请求组是独立仿真诊断，不应关闭公共接口的保护，更不能直接用于真机。两组启动前比较关节q/dq、机器人与物体初态、配置/资产/代码身份；不一致则停止该组发送，不强制设置每帧状态追随源轨迹。真实运行须另行获得授权和满足运行条件。

逐tick记录原标签、转换请求、发送目标、实际驱动目标与实测q；另外记录方块高度/位姿、原生终止和成功。RGB与物理时间戳对应，终态在自动reset前保存，提前终止时不跨reset继续执行。方块抬升只作诊断量，稳定抓取/滑落结合视频判断，不能代替原生成功判据。

即使两组某一组成功，也只说明该假设下当前场景的一次可执行性。源夹爪语义、物体/相机初态、控制时序和标定未确认前，不声称恢复原演示环境，不自动裁剪训练标签或接受全部演示。

### 无GPU数据检查

`CanonicalDataset`的默认检查拒绝空数据、非uint8图像、非有限本体/动作、逐帧元数据长度不一致，以及无效的时间戳、回合/步编号和结束标志。编号须为非负整数，时间戳须为非负有限数；可选`success=-1`表示未知，不表示失败。检查不修改原数组、不改变动作范围。

```bash
python -m unittest discover -s tests -p test_dataset_validation.py -v
```

这些合成CPU测试检查字段完整性，不证明图像/动作真实同步、源成功或物理可执行性；时间顺序和采样含义仍须按数据源确认。安装NumPy/Torch后运行，缺依赖的skip不是通过。

优先取得采集源的关节标定、单位、动作管理器/控制器配置、环境版本和相机定义。若提出转换，需在固定执行器与原限位下验证其含义，保留原始标签和转换版本；不能只为消除超限而更改范围。

若源协议无法确认，该数据继续作为诊断候选，不强行送入 BC。另行讨论在匹配环境中生成或采集可验证的成功示范。当前不启动采集、正式训练或新增模型测试。

真机仍需正式 SDK、标定、命令确认及相机/本体时间戳验收；本轮仿真结果不代替这些要求。
