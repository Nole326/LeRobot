# SO101 接口与演示数据验收

本页区分公共接口可运行与演示可用于训练。两者独立验收；环境短测通过不代表抓取成功，也不使候选数据自动成为专家演示。

## 验收对象

- 代码起点：`0d61747`，课程 LiftCube 适配器；不是 PickOrange 或正式多物体任务。
- 环境：Isaac Sim 4.5.0 / Isaac Lab 2.1.1 / LeIsaac 0.1.2 配套镜像。
- 策略输入：单 front RGB、六关节反馈与上一发送目标。兼容速度/末端补零不作真实测量使用。
- 控制：六维绝对电机目标，经公共转换发送为驱动关节目标；请求、发送与反馈分别记录。

实际部署绑定、原始运行日志和资源记录不放入公共仓库。

## 接口检查

软件回归入口见 [LiftCube AGENTS](../course/liftcube/AGENTS.md#7-改动后的最小验证)。实际环境验收需要另外核对：

1. 原生关节名称及顺序与 `JOINT_NAMES` 一致；实测关节状态不缺失、不补造。
2. 小幅诊断命令的电机值与弧度转换一致，驱动目标与发送值一致；反馈不要求瞬间到达目标。
3. 上一命令槽记录发送目标，速度/末端兼容槽保持补零；不将物体真值输入策略。
4. front 图像尺寸、数值范围与渲染就绪状态；物理步和纯渲染更新分开。
5. 原生环境周期及策略动作保持次数；终止时不继续执行缓存动作。
6. 截断时返回 reset 前末态，不能用下一回合初帧代替。

2026-10-22，以上代码完成 seed17、16 个环境 tick 的真实短测，结果 `passed`、进程自然退出码 0，优化更新为 0。部署的全部 Python 源文件 SHA 与上述提交一致。

| 实测项 | 结果 |
| --- | --- |
| 六关节顺序 | shoulder_pan、shoulder_lift、elbow_flex、wrist_flex、wrist_roll、gripper，与声明一致 |
| 命令链 | 逐 tick 请求/发送值及弧度转换一致；非终止步原生驱动目标与发送值一致，反馈与原生 joint_pos 转换一致 |
| 本体布局 | 上一发送命令正确；速度/末端兼容槽为零；16 tick 未触发限幅 |
| front RGB | 原生批量形状 1×480×640×3，策略输入 64×64×3；初始与终态图像已检查 |
| 频率 | 原生环境 60Hz；30Hz策略两tick保持复用此前未变执行层的验收，不把本次逐tick诊断说成30Hz策略测试 |
| 渲染与末态 | 40次纯渲染达到就绪，额外物理步为0；第16tick截断，适配器保留reset前末态 |

## 候选演示：尚不可直接用于正式 BC

数据：`H2Ozone/lift_cube`，revision `bd23af6c179f9b10cd1439e4e53b8e3d08da28bb`；92 回合、62180 帧、30 FPS，任务文本为 `Lift the red cube up.`。

当前主数据表 SHA256：`820a60f6fc729b644b4e1ea08de5455b360686921ddf27fb4eea4e0ca54fa26f`。本轮核对与既有审核一致，复用未变数据结论，不重新解码全量视频。

| 项目 | 已知结论 | 对训练的影响 |
| --- | --- | --- |
| 请求动作范围 | 按起点声明的单位解释，38949/62180 帧（62.64%）至少一个手臂目标越界，主要集中在腕俯仰 | 默认读取器拒绝；禁止静默裁剪标签 |
| 请求与反馈 | 请求目标和实测位置为不同字段；实际反馈常仍受机械限位约束 | 不能用同帧或下一帧反馈替代动作标签 |
| 成功证据 | 元数据/数据表无 success、reward 或可复算成功的物体高度 | 回合结束不等于任务成功，不能报告专家成功率 |
| 相机 | 原始 front 为 480×640；已抽查画面与当前环境视角/外观不完全相同 | 同名相机不能证明标定相同；resize 不解决域差异 |
| 数据划分 | 发布元数据将全部回合标为 train | 正式训练前须另做回合级、必要时场景级隔离 |

首次元数据与动作统计、八个回合首末帧抽查均为既有证据，不宣称本轮重新完成全数据视觉审核。文件边界构造的 `terminated` 与 `success=-1`（未知）不能当原生成功或离线 RL 终止标签。

## 下一步通过条件

优先取得采集源的关节标定、单位、动作管理器/控制器配置、环境版本和相机定义。若提出转换，需在固定执行器与原限位下验证其含义，保留原始标签和转换版本；不能只为消除超限而更改范围。

若源协议无法确认，该数据继续作为诊断候选，不强行送入 BC。另行讨论在匹配环境中生成或采集可验证的成功示范。当前不启动采集、正式训练或新增模型测试。

真机仍需正式 SDK、标定、命令确认及相机/本体时间戳验收；本轮仿真结果不代替这些要求。
